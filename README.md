# RS-Agent L2 · 遥感指数智能问答

上传一景多波段影像，用一句话提问，得到对应指数的热力图、统计摘要和一段带数据边界的解读。

本地优先：波段识别、指数路由、计算渲染全部在本机完成；只有本地判断不了时，才把**文字**交给大模型，影像像元不出本机。

![指数热力图示例](docs/images/gallery.jpg)

---

## 这是什么

一个跑在本地浏览器里的遥感分析小工具。它不是"上传一张图，把十个公式全算一遍"，而是按你的问题挑指数：

- 说"湖泊水质怎么样"，只算 NDWI 和 NDTI；
- 说"这里适合建房子吗"，只算 NDBI、NDWI、SAVI；
- 说"帮我看看"，它不猜，反问你到底想看什么。

支持标准指数 9 个（NDVI / NDWI / NDBI / RVI / SAVI / NBR / BSI / NDTI / NBR2），以及两个非标准指标（LAI、chl_proxy），后者在界面、热力图标题和回复里都会被显式标注。

## 处理流程

![处理流程](docs/images/workflow.png)

**三层路由**

| 层级 | 触发条件 | 行为 |
| --- | --- | --- |
| 1. 本地字典 | 问题和内置关键词/句式匹配 | 直接确定指数，不调用任何外部接口 |
| 2. 大模型语义路由 | 本地一条都没命中 | 把原话和工具定义交给模型，由它从白名单选指数 |
| 3. 反问 | 模型也判断不出，或问题过于笼统 | 用自然语言反问，不猜、不算 |

## 核心特性

- **一个文件就够** — 已是多波段 GeoTIFF 的直接上传；单波段文件一次多选也能内部合成
- **波段推断本地优先** — 文件名（`LC08`、`S2A`、`GF1`）、元数据、传感器模板依次判断；也可以直接写"红光 4、近红外 5"
- **按问题挑指数** — 多场景同时命中时只算最核心的 2 个（单一综合体检最多 3 个），其余以"建议"提示
- **两套掩膜** — 陆地指数剔除水体、云和阴影；水体指数保留水体，只剔云影
- **先出图，后出结论** — 本地路由命中时，热力图和统计摘要约 1 秒先显示，顾问结论随后补上
- **缺波段不报错** — 没有短波红外就不出 NDBI，回复里说明缺什么、为什么，其余指数照常输出
- **变化类问题不硬答** — 只有单期影像时，"退化了吗""变化大吗"会直接说明需要两个时相
- **不夸大结论** — 未标定的指数只做数值引用和本景内相对比较，不使用"优/良/差""清澈/浑浊"等级词

## 快速开始

### 1. 环境

- Python 3.10 及以上（实测 3.13）
- Windows 10/11 双击 `run.bat`；macOS / Linux 用 `run.sh`
- 联网非必需：不配 API Key 时以纯本地模式运行

### 2. 安装依赖

```bash
python -m pip install -r requirements.txt
```

依赖：`gradio`、`openai`、`python-dotenv`、`numpy`、`matplotlib`、`rasterio`

### 3. 配置模型（可选）

不配也能跑，只是没有大模型路由和顾问结论。需要时把 `.env.example` 复制成 `.env`：

```ini
MOONSHOT_API_KEY=sk-你的密钥
LLM_MODEL=kimi-k2.6
```

> `.env` 里是你的私钥，不要提交或打包发布。

### 4. 启动

**Windows**：双击 `run.bat`

**命令行**：

```bash
python app.py
```

浏览器打开 <http://127.0.0.1:7860>。端口被占用时 Gradio 会顺延到 7861、7862，以控制台输出为准。

### 5. 使用

1. 上传一个多波段 GeoTIFF（或一次多选同景的单波段文件）
2. 输入问题，例如：
   - `这里生态环境怎么样？假设这是 Landsat 8 影像。`
   - `这片湖泊水质怎么样？`
   - `这片庄稼地发育可以吗`
3. 点击发送，左侧看结论，右侧看热力图

## 指数路由规则

| 你说的关键词 | 计算的指数 |
| --- | --- |
| 植被、绿化、长势、农作物、农田、森林、林地 | NDVI |
| 上一条 + 干旱、稀疏 | 追加 SAVI |
| 上一条 + 茂密 | 追加 RVI |
| 叶面积、LAI | 追加 LAI |
| 水体、湖泊、河流、淹没、水域面积 | NDWI |
| 水质、浑浊、泥沙、污染、浊度 | NDTI |
| 水华、藻类、富营养化 | chl_proxy |
| 城市、建筑、房屋、违建、不透水面 | NDBI |
| 上一条 + 区分裸土 | 追加 BSI |
| 裸地、沙化、土地退化、开挖 | BSI |
| 火灾、着火、火烧迹地、过火面积 | NBR |
| 生态环境、全面体检 | NDVI + NDWI + NDBI |
| 适合建房子、建房、开发建设 | NDBI + NDWI + SAVI |
| 水环境、水情、水体状况 | NDWI + NDTI |
| 变化、变好、改善、退化了吗 | 单期数据不计算，提示需要两个时相 |

直接点名指数（如"算一下 NDVI 和 NDTI"）优先级最高，会覆盖上面的推断。

## 输出示例

以"这里是不是有水华？"为例（节选）：

```text
【统计摘要】
chl_proxy均值为0.02，25%/50%/75%分位数为-0.04/0.02/0.09；
绿光相对占优（chl_proxy>0）的水面像元占比约59.5%。

【指数路由】本次计算：chl_proxy（自制代理，非标准指数）。

【数据局限性】chl_proxy 仅为蓝光/绿光波段的归一化差值代理……
它不能换算为叶绿素 a 绝对浓度（μg/L），也无法区分藻类、悬浮泥沙与有色溶解有机物。

【分析结论】
基于本次计算的 chl_proxy，无法判定该区域已发生水华……该指标为单期遥感代理参数，
未经原位叶绿素 a 浓度实测标定，不足以作为水华发生的确定性证据。
```

## 输出文件

- 每次请求独占一个目录：`indices_output/runs/run_xxxxxx/`
- 目录内含热力图（`ndvi.png` 等）、中间文件（`processed.tif`、`mask.npy`、`mask_ndwi.npy`）
- 默认保留最近 10 次运行，更早的自动清理
- 热力图配色：NDVI 类用红-黄-绿，水体类用红-蓝；色条刻度是真实指数值，按有效像元 2%–98% 分位数拉伸

## 已知限制

- **仅支持单期影像。** 退化、变化、趋势类问题会被拒绝，并提示补充第二个时相
- **指数只反映光谱特征。** 未经实测标定，不能换算成浊度（NTU）、叶绿素浓度或水质等级，只能做本景内的相对比较
- **`LAI` 与 `chl_proxy` 不是标准指数。** 前者是 `0.5×RVI−1` 的经验式，后者是绿/蓝波段的代理指标，图标题会标注
- **问答是单轮的。** 每次发送都是独立请求，不会记住上一轮的问题。反问后会保留已上传的影像，可以直接作答，但回答里最好带上你想看的对象（例如"看水体"而不是"看第一个"）
- **云/阴影检测是启发式规则。** 没有读取 QA 波段，复杂场景（薄云、地形阴影）可能被误判
- **大影像会降采样。** 超过约 400 万像素时按显示尺寸读取，统计量基于降采样结果

## 配置项

| 变量 | 说明 | 默认值 |
| --- | --- | --- |
| `MOONSHOT_API_KEY` | 模型 API Key，不填则纯本地模式 | — |

| `GRADIO_SERVER_PORT` | 服务端口 | `7860` |

## 常见问题

**Q：启动后 7860 是别的页面？**
端口被占用了。看控制台打印的实际地址，通常是 7861。

**Q：为什么少了一张 NDBI 热力图？**
影像没有短波红外波段。回复框会说明缺少什么、对应的计算公式，其余指数照常输出。

**Q：可以离线用吗？**
可以。没有 `.env` 或设置 `USE_LLM=false` 时，只有本地关键词能匹配的问题有效，匹配不到会反问，全程不联网。

**Q：能部署到服务器给别人用吗？**
当前是单用户本地设计：没有登录鉴权，输出目录也是共享的。多人使用前需要先做请求隔离和限流。
